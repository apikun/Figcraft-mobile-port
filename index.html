The open-source design tool from the ArtCraft community, ported to the web as a WebAssembly app and tuned for touch. Frames, auto layout, components, vector networks, styles, variables and prototypes — all on your phone.

WebGPU with WebGL2 fallback · ~7 MB download, cached after first load

📱 Made to work on mobile

The stock web build isn't touch-first, so this port adds a gesture adapter that translates multi-finger input into the engine's native mouse and zoom pathways.

👆

One finger

Tap to select, drag to move shapes and drag on empty canvas to marquee-select — just like a mouse.

🤏

Pinch to zoom

Two fingers pinch or spread zooms the canvas smoothly, mapped to the engine's native zoom input.

✌️

Two-finger pan

Slide two fingers to pan the canvas. The gesture adapter drives the engine's middle-button pan path.

📲

Built for small screens

The editor fills the viewport edge-to-edge with browser zoom and rubber-band scrolling locked out.

Built with the real engine

Every screen below ships as an example file in the repository and renders live in the editor.

⚡ Everything in the toolkit

▦

Frames & auto layout

Responsive layouts with hug/fill sizing, nested containers and padding controls that reflow as you edit.

⧉

Components & variants

Reusable main components with instances, overrides and variant switching across your whole document.

✎

Vector networks

A full vector editor: pen tool, boolean operations, corner radius, width profiles and path editing.

◐

Styles & variables

Shared colour, text and effect styles plus variables with modes — one set of tokens, light and dark.

▷

Prototyping

Wire flows with interactions, then present them right in the browser with responsive previews.

⤓

Figma import

Open .fig files directly — the engine reads Figma's Kiwi-serialized document format natively.
